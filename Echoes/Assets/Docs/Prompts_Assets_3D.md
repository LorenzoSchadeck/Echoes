# Echoes: prompts de assets 3D (multi-view)

Cada asset tem três imagens: frente, lado e trás. Cada prompt já vem completo, com o sufixo. O negative prompt é o mesmo para as três imagens do asset.

Para as três vistas saírem do mesmo objeto: gere a frente primeiro e use a mesma seed nas outras duas. Se o gerador aceitar imagem de referência, passe a frente como referência para o lado e para trás.

**Limites de peso**

- **Objeto pequeno:** até 2 mil triângulos, textura 1K.
- **Objeto médio:** até 8 mil triângulos, textura 1K a 2K.
- **Móvel grande:** até 15 mil triângulos, textura 2K.

- **Livros:** gere os dois livros soltos. Eu junto em fileiras de uns 20 no Blender ou no Unity, com cores e alturas variadas, para trocar os 832 livros soltos da cena.
- **Fita de isolamento esticada:** fica fora da lista. Eu faço no Unity com uma faixa reta e textura, para ela se ajustar a qualquer distância entre os cavaletes.
